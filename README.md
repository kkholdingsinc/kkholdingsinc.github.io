# KK Holdings Digital Contact Card

Digital contact card for Kosei Kobayashi, President & CEO, KK Holdings Inc.

## Files
- `index.html` — main page
- `style.css` — visual styling
- `kosei-kobayashi.vcf` — downloadable contact card
